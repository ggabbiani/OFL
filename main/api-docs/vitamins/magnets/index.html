    module fl_magnet

    Syntax:

    fl_magnet(verbs=FL_ADD,type,nop_screw,direction,octant)

    Context variables:

    Name Context Description
    $fl_tolerance Parameter modify the object size during FL_FOOTPRINT
    $fl_thickness Parameter thickness for screws during FL_DRILL and FL_MOUNT
    $mag_h Children magnet height

    TODO: the screw used during FL_MOUNT is built with a shaft length equal to the magnet height + $fl_thickness. A better solution would be to use an externally provided screw passed as a child.

    Parameters:

    verbs
    supported verbs: FL_ADD, FL_ASSEMBLY, FL_BBOX, FL_DRILL, FL_FOOTPRINT, FL_LAYOUT

    type
    magnet object

    nop_screw
    nominal screw overloading from NopSCADlib specifications

    direction
    desired direction [director,rotation], native direction when undef

    octant
    when undef native positioning is used (+Z)
